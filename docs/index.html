Measured on real hardware with netem, the native library cuts worst-case round-trip latency 6x below the operating system's default at 5% packet loss and 12x at 20%, at the cost of bulk throughput, which the default wins by 27x. The tradeoff is the point: this is a transport for small urgent messages on links you control.
